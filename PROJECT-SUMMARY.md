# Adam Khier — Portfolio — Project Summary

> Reconstructed 22 Nov 2026 from the repository itself, not from chat history.

## What it is
A hand-built single-page portfolio: hero, project grid, about, toolbox and contact — no framework, no build step.

## Stack
HTML, CSS and a little vanilla JavaScript. Paper/ink design system with a paper and night theme; particle hero, scroll reveals, project filters, card tilt.

## How to view
```bash
python3 -m http.server 8000
# http://localhost:8000
```
Or open `index.html` directly.

## Files
- `index.html` — hero, projects, about, toolbox, contact
- `styles.css` — design system, both themes, responsive rules
- `app.js` — particles, reveals, filters, tilt, theme toggle

## Status
Content-complete but **not deployed**. Any static host works — GitHub Pages is the documented option (Settings → Pages → deploy from `main`, root).

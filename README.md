# Adam Khier — Portfolio Site

Hand-built single page portfolio. No framework, no build step: just HTML, CSS and a little JavaScript.

## View it

Open `index.html` in a browser, or serve the folder:

```bash
cd portfolio
python3 -m http.server 8000
# → http://localhost:8000
```

## What's inside

| File | What it is |
| --- | --- |
| `index.html` | Hero, project grid, about, toolbox, contact |
| `styles.css` | Paper/ink design system, paper + night themes, responsive |
| `app.js` | Particle hero, scroll reveals, project filters, card tilt, theme toggle |

## Deploy

Any static host works (GitHub Pages: Settings → Pages → Deploy from branch → `main` + `/ (root)`).
